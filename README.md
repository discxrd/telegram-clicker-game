# Telegram clicker project

A Telegram mini-app and bot with a clicker game, player balances, upgrades, and a Go service. The repository contains the bot backend and regional frontend assets.

## Source layout

- `bot/backend/` contains the Go API, database operations, and bot integration.
- `bot/frontend/` contains the web interface.
- `france/` and `portugalia/` contain market-specific project files.

The original workspace also had local environment files and generated build output. Those are excluded from this repository. Configure credentials through environment variables before running any service.
